# 🕛Relógio Mundial

Uma aplicação que permite visualizar o horário atual de diferentes cidades e fusos horários ao redor do mundo.

## Funcionalidades

- Exibição de diferentes fusos horários
- Atualização do horário em tempo real
- Consulta do horário de diferentes cidades
- Interface interativa

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
